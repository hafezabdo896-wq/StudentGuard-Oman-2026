# StudentGuard — دليل التشغيل السريع

## 1) المتطلبات
- جهاز Windows 10 أو 11.
- Python 3.10 أو أحدث.
- اتصال إنترنت أول مرة لتثبيت المكتبات.

## 2) فك الضغط
فك ضغط `StudentGuard.zip` في مجلد واضح مثل سطح المكتب.

## 3) فتح موجه الأوامر داخل المجلد
افتح مجلد StudentGuard، ثم اضغط على شريط العنوان أعلى نافذة المجلد، واكتب `cmd` ثم Enter.

## 4) تثبيت المكتبات
اكتب الأمر التالي واضغط Enter:
```bash
python -m pip install -r requirements.txt
```

## 5) تشغيل التطبيق
اكتب:
```bash
python -m streamlit run app.py
```
ستفتح صفحة StudentGuard في المتصفح تلقائيًا. إذا لم تفتح، انسخ العنوان الذي يظهر في نافذة الأوامر (غالبًا http://localhost:8501) وافتحه في المتصفح.

## 6) تجهيز عرض الغد
1. افتح صفحة «إدارة الطلبة».
2. افتح القسم «إضافة بيانات تجريبية للعرض» واضغط «إضافة 3 طلبة تجريبيين».
3. سجل حضورًا لطالب، ثم سجل واقعة سلوكية.
4. افتح «الإجراءات التربوية» وأضف إجراءً مقترحًا أو معتمدًا تجريبيًا.
5. افتح «التقارير» لعرض ملف الطالب وسجل العمليات.

## 7) قاعدة البيانات
ينشئ التطبيق ملف `studentguard.db` تلقائيًا في نفس المجلد عند أول تشغيل. لا تحذف هذا الملف إذا أردت الاحتفاظ بالبيانات. خذ نسخة منه احتياطيًا قبل أي تحديث.

## 8) عرض التطبيق على جهاز آخر
- للعرض على نفس شبكة المدرسة: شغّل التطبيق على جهازك باستخدام:
```bash
python -m streamlit run app.py --server.address 0.0.0.0
```
- اعرف عنوان IP للجهاز من `ipconfig` في نافذة CMD، ثم افتح على الجهاز الآخر:
`http://IP-ADDRESS:8501`
- يجب أن يكون الجهازان على شبكة Wi-Fi نفسها، وقد يمنع جدار الحماية الاتصال. لا تفتح التطبيق على الإنترنت العام ولا تستخدم بيانات طلبة حقيقية في العرض التجريبي.

## تنبيه مهم
هذه نسخة أولية للعرض وليست نظامًا رسميًا معتمدًا. تصنيفات السلوك والتوصيات قابلة للمراجعة، ويجب مطابقة أي قرار مع أحدث لائحة معتمدة من وزارة التربية والتعليم وإجراءات المدرسة. لا تعتمد تنظيف الساحة أو أي نشاط كعقوبة تلقائية؛ يجب أن يكون نشاطًا تربويًا آمنًا ومناسبًا وبموافقة الإدارة، مع مراعاة كرامة الطالب وسلامته.
